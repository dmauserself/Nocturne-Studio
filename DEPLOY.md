# Публикация сайта

Сайт публикуется на **Netlify**: бесплатный тариф разрешает коммерческие сайты, даёт HTTPS и
бесплатный адрес вида `имя.netlify.app`. Заявки с формы приходят в **Telegram**.

> Почему не Vercel: бесплатный тариф Vercel (Hobby) по правилам только для некоммерческих проектов.
> Код готов и для Vercel (`api/lead.ts`), если у вас платный тариф Pro.

---

## Шаг 0. Перед публикацией: замените демо-контент ⚠️

Сейчас на сайте **вымышленные** данные. Показывать их клиентам как настоящие нельзя: выдуманные отзывы,
кейсы и цифры — это недостоверная реклама (ст. 5 закона «О рекламе»). Всё меняется в `src/content.ts`:

- [ ] `FOOTER` — e-mail, телефон, адрес, ссылки на соцсети (сейчас `hello@nocturne.studio`, `+7 (495) 000-00-00`)
- [ ] `TESTIMONIALS` — только реальные отзывы с согласия клиентов, либо уберите секцию
- [ ] `PROJECTS` — реальные кейсы (сейчас придуманные бренды «Полярис», «Северный мёд» и др.)
- [ ] `TEAM` — реальные люди и должности
- [ ] `PRESENCE.cards` — цифры «50+ проектов», «97% клиентов» должны быть правдой
- [ ] `PHILOSOPHY` и `FAQ` — цены и сроки
- [ ] `BRAND` — если название агентства другое
- [ ] `public/privacy.html` — впишите реквизиты владельца вместо `[в квадратных скобках]`
- [ ] Фото — см. `src/assets/README.md`

## Шаг 1. Telegram-бот для заявок (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и логин бота.
   BotFather пришлёт **токен** вида `123456789:AAH...`. Никому его не показывайте.
2. Найдите своего бота и нажмите **Start** (напишите ему любое сообщение).
3. Откройте в браузере (подставьте токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   Найдите `"chat":{"id":123456789` — это **chat id**.
   - Хотите получать заявки в группу? Добавьте бота в группу, напишите там сообщение и снова откройте ссылку.
     id группы начинается с минуса: `-100…`.
   - Несколько получателей — через запятую: `111111,-100222222`.

## Шаг 2. Аккаунт Netlify

Зарегистрируйтесь на **https://app.netlify.com/signup** (можно через e-mail или GitHub). Бесплатно.

## Шаг 3. Публикация (в терминале, в папке проекта)

```bash
npx netlify-cli login
```
Откроется браузер — нажмите **Authorize**.

```bash
npx netlify-cli sites:create --name nocturne-studio
```
Имя — это ваш будущий адрес `nocturne-studio.netlify.app`. Если занято, выберите другое.

```bash
npx netlify-cli env:set TELEGRAM_BOT_TOKEN "ваш_токен"
```
```bash
npx netlify-cli env:set TELEGRAM_CHAT_ID "ваш_chat_id"
```

```bash
npx netlify-cli deploy --prod
```
В конце появится ссылка **Website URL** — сайт в сети. Отправьте с него тестовую заявку и
проверьте, что она пришла в Telegram.

Обновить сайт после правок — ту же команду `deploy --prod`.

## Шаг 4. Домен

**Бесплатно:** `имя.netlify.app` — работает сразу, с HTTPS. Сменить имя:
Netlify → Site configuration → Change site name.

**Свой домен** (`nocturne.ru` и т. п.): полностью бесплатных надёжных доменов не существует,
но `.ru` стоит ~200–900 ₽ в год (REG.RU, RU-CENTER, Timeweb и др.).

1. Купите домен у регистратора.
2. Netlify → **Domain management** → **Add a domain** → введите домен.
3. У регистратора в настройках DNS укажите:
   - запись **A** для `@` → `75.2.60.5`
   - запись **CNAME** для `www` → `nocturne-studio.netlify.app`
4. Через 15 минут – 24 часа домен заработает, HTTPS Netlify выпустит сам.

## Шаг 5. Аналитика (по желанию)

1. Создайте счётчик на **https://metrika.yandex.ru** (адрес — ваш домен).
2. В счётчике: **Цели → Добавить цель → JavaScript-событие**, идентификатор `lead`.
   Так Метрика будет считать отправленные заявки (конверсию).
3. Передайте номер счётчика сайту и опубликуйте заново:
   ```bash
   npx netlify-cli env:set VITE_YM_ID "12345678"
   ```
   ```bash
   npx netlify-cli deploy --prod
   ```

> С включённой Метрикой сайт собирает cookie — это уже описано в `public/privacy.html`.
