# NOCTURNE STUDIO — лендинг креативного агентства

Vite + React + TypeScript + Tailwind CSS, Framer Motion, Lenis.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр собранной версии
```

- Тексты: `src/i18n/ru.ts` (основной язык) и `src/i18n/en.ts` — английская версия по кнопке RU | EN или ссылке `?lang=en`
- Цвета: CSS-переменные в `src/index.css` + `tailwind.config.ts`
- Замена изображений: `src/assets/README.md`
- Публикация, домен, заявки в Telegram, аналитика: `DEPLOY.md`
